# OBS-Virtual-Camera-Name-Manager
一个用于修改和恢复 OBS Virtual Camera 显示名称的轻量 Windows 工具

它可以自动识别 OBS 虚拟摄像头相关配置项，批量修改设备显示名称，并在首次修改前自动保存原始配置，支持后续一键恢复。

相比手动打开注册表逐项查找和修改，这个工具把整个流程做成了可视化操作，更适合需要频繁调整设备名称、区分摄像头设备或处理软件兼容问题的用户。

## 主要功能

- 自动识别 OBS Virtual Camera
- 自定义虚拟摄像头显示名称
- 自动批量修改相关配置项
- 首次修改前自动备份原始配置
- 一键恢复原始名称
- 修改后自动读取并验证结果
- 写入失败时自动回滚
- 管理员权限检测与 UAC 提权
- 支持 Windows 10 / Windows 11
- 支持中文名称、英文名称及常规字符
- 提供详细配置项与操作日志查看

## 使用方式

1. 启动程序
2. 等待程序自动识别 OBS Virtual Camera
3. 输入新的设备名称
4. 点击「修改名称」
5. 根据提示授予管理员权限
6. 修改完成后，重新打开需要使用摄像头的软件

如果需要恢复，只需点击：

**恢复原始名称**

程序会读取首次修改前保存的配置，并恢复原始设备名称。

## 安全设计

程序不会直接全局替换注册表中的 `OBS Virtual Camera` 字符串。

在执行修改之前，会先识别和确认目标配置项，并保存原始值。每次写入完成后还会重新读取结果进行验证。

如果批量修改过程中出现异常，程序会尝试将已经修改的配置项恢复到本次操作前的状态。


首次创建后不会被后续改名操作覆盖。
适用场景
例如：
- 自定义 OBS Virtual Camera 的设备名称
- 多摄像头环境下更方便地区分设备
- 简化 OBS 虚拟摄像头相关注册表配置
- 解决部分软件中的设备名称显示问题
- 不想手动使用 regedit 修改多个注册表项目
项目原则
本项目仅用于管理 Windows 中 OBS Virtual Camera 的设备显示名称。
它不会：
- 修改 OBS 核心文件
- 修改 OBS 插件或 DLL
- 安装或替换摄像头驱动
- 删除、禁用或卸载设备
- 注入其他应用程序
- Hook 其他程序
- 提供任何平台规避或反检测功能
项目重点是提供一个 简单、可恢复、尽量安全的 OBS 虚拟摄像头名称管理工具。
